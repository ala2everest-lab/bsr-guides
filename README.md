# BSR Guides — guides.bsrhrb.com

Plain-English guides to Building Safety Regulator approval for flat works in higher-risk buildings (England), by Alicja Salter.

- Guides live in `content/` as Markdown with a short header (order, slug, h1, title, description, reviewed dates).
- Run `python3 build.py` to rebuild the site into `docs/` (served by GitHub Pages, custom domain `guides.bsrhrb.com`).
- New guides are added as a pull request for Alicja to review; merging publishes them.
